## Что уже сделано

### 1. Переписан [config/corne.keymap](config/corne.keymap)

- **Базовый слой (DEF):** 30 буквенных клавиш как было. `LGUI` и `RSHFT` поменяны местами относительно дефолта: `LGUI` теперь на правом внешнем пинки (row 3), `RSHFT` на левом внешнем thumb. (Раньше пробовали LGUI на thumb / RSHFT на пинки, но пользователь предпочёл такой свап.)
- **NAV:** стрелки пирамидкой на левой руке (↑ на D, ←↓→ на XCV — текущая позиция, не сдвинули вниз потому что физически не помещается, нижний ряд граничит с thumb-cluster). Убран дублирующий нумпад. На правой home row линейно `HOME PgUp PgDn END` («начало → вверх → вниз → конец»). `BTAB` (Ctrl+Tab) сохранён на F-позиции, `&caps_word` на месте Tab.
- **SYM:** правая половина оставлена **как в исходной раскладке** (пользователь сказал, что так привычнее). Правки только на левой стороне — добавлены символы, которые иначе пропали бы: `"` на A, `?` `/` парой на D F, `<` `>` парой на C V (под `?` `/`). `! @ # $ %` верхний ряд, `` ` `` `~` на G B как было.
- **ADJ:** починен сломанный thumb-row (было 4 биндинга вместо 6). Убраны дублирующие стрелки на правой руке (они теперь только на NAV).
- Удалены неиспользуемые behaviors: `hm` (homerow mods), `para`, `paraless`, `paragreat`, кастомный `caps`. Использован встроенный `&caps_word`.
- Все ячейки выровнены на 13 символов через `#define`-алиасы (`BTAB`, `CAPS`, `SUNL`, `BOOT`, `BT0`-`BT2`, `BTC`, `BTCA`).
- Над каждым слоем — ASCII-сетка для слепой печати.

### 2. Создан [KEYMAP.md](KEYMAP.md)

Шпаргалка с двумя версиями раскладки (до изменений / после), ASCII-диаграммы по слоям, дифф изменений на каждом слое.

## Принятые решения (не пересматриваем без причины)

| Что | Решение | Почему |
|---|---|---|
| База раскладки | Остаёмся на QWERTY | Чтобы не ломать мышечную память + ЙЦУКЕН OS-layout сидит на тех же позициях |
| Homerow mods | Не используем | Пользователь начинающий, не готов |
| Зеркальные модификаторы (J/S K/C итд) | Не используем | По той же причине |
| Стрелки | Пирамидкой на левой руке (↑ D / ←↓→ XCV) | Текущая позиция, ниже не помещается |
| Win / RSHFT | LGUI на правом внешнем пинки, RSHFT на левом внешнем thumb | Текущий выбор пользователя (2026-05-08); ранее пробовали наоборот |

## Открытые вопросы (задать пользователю)

1. **Кириллица — ё, ъ.** На стандартном ЙЦУКЕН они на `]` и `` ` `` — этих физических клавиш на Corne нет. Варианты:
   - Combo (тап двух клавиш одновременно): например `л+о` = ё
   - Tap-dance: двойной тап `е` → ё, `ь` → ъ
   - Mod-morph: RAlt+е = ё, RAlt+ь = ъ (RAlt уже на правом thumb на базе) — **рекомендованный**
   - Отдельный CYRILLIC слой
2. **OLED-дисплей.** В [config/corne.conf](config/corne.conf) `CONFIG_ZMK_DISPLAY=n` закомментирован. Включить и показывать имя текущего слоя?
3. **Автогенерация SVG-шпаргалки** через keymap-drawer + GitHub Action на каждый push в `master`?
4. **Прошивка и тест.** Новая раскладка ещё не залита на клаву. Перед прошивкой пользователь хотел мысленно проверить набор типовых строк — `if (x == 0) { return; }`, `git commit -m "..."`. Если что-то ощущается неудобно — поправить **до** прошивки.
