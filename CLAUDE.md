# Контекст для Claude

Этот репозиторий — прошивка ZMK для клавиатуры Corne v3 (3×6 + 3 thumb на сторону, 42 клавиши).

**Текущее состояние работы по раскладке: см. [SESSION.md](SESSION.md).**
В нём — все принятые решения, открытые вопросы, изменения файлов и список того, что ещё нужно обсудить с пользователем. **Прочитай SESSION.md прежде чем продолжать работу по раскладке** — там зафиксирован весь контекст обсуждений.

## Профиль пользователя

- Русскоязычный, билингвальный набор EN/RU
- ЙЦУКЕН берётся через OS-уровень (не через отдельный слой клавы)
- Linux
- Начинающий пользователь ZMK — не использует homerow mods, предпочитает понятные/простые конструкции
- Не хочет менять мышечную память на 30 буквенных клавишах базы (QWERTY как есть)

## Структура проекта

- [config/corne.keymap](config/corne.keymap) — основная раскладка
- [config/corne.conf](config/corne.conf) — флаги ZMK (RGB, OLED — пока выключены)
- [KEYMAP.md](KEYMAP.md) — шпаргалка раскладки (до/после), ASCII-диаграммы по слоям
- [SESSION.md](SESSION.md) — состояние обсуждения с пользователем
- [boards/shields/](boards/shields/) — определение шилда Corne v3
- [build.yaml](build.yaml) — что собирать в CI
